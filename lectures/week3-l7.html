Covariance

Variance

np.var()

Measures how widely the values of a single variable spread around its mean.

Covariance

np.cov()

Measures whether two variables tend to move together.

Cov(X,Y) > 0: they tend to move in the same direction.
Cov(X,Y) < 0: they tend to move in opposite directions.

Covariance is scale-variant, meaning its value is sensitive to the units we use.

Var(X) = 1.60
Var(Y) = 1.60
Cov(X,Y) = 0.80

Pearson's Correlation

scipy.stats.pearsonr()

Measures the strength and direction of a linear relationship after removing the effect of scale. ρ ranges between -1 and 1.

ρX,Y = Cov(X,Y) σX σY

ρ(X,Y) = 1: perfect positive linear relationship.
ρ(X,Y) = 0: no linear relationship.
ρ(X,Y) = -1: perfect negative linear relationship.

Correlation is scale-invariant: changing the units does not change its value.

Var(X) = 1.60
Var(Y) = 1.60
ρ(X,Y) = 0.50

Significance of Correlation

1. Define H₀ and H₁ 2. Define a distance 3. Simulate randomness 4. Set a threshold 5. Compare OBS data

Null hypothesis (H₀): X and Y are not correlated: ρ = 0.

Alternative hypothesis (H₁): X and Y are correlated: ρ ≠ 0.

|ρ| is the distance from zero: larger values indicate a stronger departure from H₀.

X and Y are independently drawn from a standard Normal distribution.

Choose α = 0.05. Because ρ can be positive or negative, this is a two-sided test: shade 2.5% in each tail.

Observations falling in the shaded tails are statistically significant at the 5% level.

r, p = scipy.stats.pearsonr(x, y)

p-value: if H₀ were true, the probability of obtaining a correlation this large or more extreme.

Set significance level (α) = 0.05.
This is an arbitrary convention, not a truth or a golden standard.

p-value < 0.05
Reject H₀: the correlation is statistically significant.

VS

p-value ≥ 0.05
Do not reject H₀: the evidence is not strong enough.

p < 0.01

Bootstrapping

Want to do bootstrapping more rigorously?

Bootstrapping is a non-parametric method for estimating uncertainty.
It does not require us to assume that the data follow a Normal distribution.

It repeatedly resamples (with replacement) the same amount of data from the original data and see how much the result changes.

for ct in np.arange(N_boot):
    Resample your data with replacement
    Calculate statistics using resampled data
    Save calculated statistics in an array

Evaluate the confidence interval of statistics

Because 0 is inside the 95% confidence interval (C.I.), the correlation is not statistically significant.

Like 0.05 for α (the significance level), 95% C.I. (the confidence interval) is also by choice.

When the data are not Normally distributed, the p-value returned by the package may not be reliable.
